Petya_Ai ЗАВЕРШЕНО

Умный Discord бот с искусственным интеллектом

Petya_Ai - это инновационный Discord бот, использующий современные технологии искусственного интеллекта для улучшения взаимодействия на серверах. Бот умеет поддерживать осмысленные диалоги, есть команды для развлечений и многое другое!

Основные возможности включают в себя: естественное общение, развлечения, инструменты, экономика.

Версии и обновления

Версия 2.7.0

11 июня 2026

Исправления и Улучшения + новая команда

Исправления:

  • Исправлены ошибки при взаимодействии с кнопками в модуле entertainment

Улучшения:

  • Улучшена гибкость для ИИ - Теперь Петя сам решает отвечать или добавлять упоминание пользователю через теги.
  • Команды /work и /treasure - Стали гибкими и не жёстко привязанными к коду, теперь всё настраивается через .json файлы.
  • Так же добавлена команда /leaderboard с просмотром статистики по богатству и уровню.
  • Изменено использование моделей - теперь токен настраивается из models.json
  • Модули теперь грузятся из своих папок - это нужно чтоб разделить монолитные модули на отдельные файлы с командами.
  • Пока что модули не разделены, просто перемещены в папки.

Версия 2.1.0

23 июля 2025

Переписаны все команды с нуля и добавлены новые.

🤖 Искусственный Интеллект

  • /ask question: - Задать вопрос ИИ
  • /define term: - Определить термин
  • /get parameter: (system_prompt) - Получить параметр
  • /history limit: - История запросов
  • /model_info - Информация о модели
  • /queue_info - Информация об очереди
  • /reset parameter: (context, system_prompt, all) - Сбросить параметры
  • /set parameter: (system_prompt) value: - Установить параметр
  • /set_model mode: (Petya_Ai-IM2, Petya_Ai-IM2.5) - Выбрать модель
  • /summarize text: - Суммаризировать текст
  • /translate text: language: - Перевести текст

🎪 Развлечения

  • /8ball question: - Магический шар
  • /interact_bang user: - Выстрелить в пользователя
  • /interact_bye user: - Попрощаться
  • /interact_hi user: - Поздороваться
  • /interact_kiss user: cheeks: (True, False) - Поцеловать
  • /joke - Случайная шутка
  • /quote - Случайная цитата
  • /roll max_number: - Случайное число

💰 Экономика

  • /bank action: (create, list, rename, set_comission, set_service, info) name: set_comission: set_service, new_name - Управление банком
  • /deposit amount: currency: (Медные монеты, Серебряные монеты, Золотые монеты, Платиновые монеты) - Внести депозит
  • /exchange amount: from_currency: (Медные монеты, Серебряные монеты, Золотые монеты, Платиновые монеты) to_currency: (Медные монеты, Серебряные монеты, Золотые монеты, Платиновые монеты) - Обмен валюты
  • /inventory - Инвентарь
  • /profile create: (True, False) user: - Профиль
  • /set_bank name: - Установить банк
  • /shop black_store: (True, False) - Магазин
  • /transfer amount: currency: (Медные монеты, Серебряные монеты, Золотые монеты, Платиновые монеты) user: - Перевести деньги
  • /withdraw amount: currency: (Медные монеты, Серебряные монеты, Золотые монеты, Платиновые монеты) - Снять деньги
  • /work profession_list: (True, False) - Работа
  • /treasure - Поиск различных вещей

🛠️ Инструменты

  • /avatar user: - Аватар пользователя
  • /bot_channel action: (Установить канал, Сбросить настройки, Показать текущий) channel: - Управление каналом бота
  • /emoji action: (send, info) emoji: format: (png, gif) - Информация об эмодзи
  • /emoji_list server_id: - Список эмодзи сервера
  • /feedback - Обратная связь
  • /info bot_started: (True, False) - Информация о боте
  • /invite - Пригласить бота
  • /ping - Проверка задержки
  • /say text: - Сказать от имени бота
  • /servers content: (True, False) - Список серверов
  • /help category: (Искусственный Интеллект, Развлечения, Экономика, Инструменты) - Эта команда
  • /set_group user: group: (пользователь, покупатель, тестер, создатель) - Установить группу (только создатель)
  • /reboot - Перезагрузить бота (только создатель)
  • /shutdown - Выключить бота (только создатель)
